# ANIMO-RG07 Post-KT16 Program Rebaseline

## Purpose

RG07 is a governance-only rebaseline after the bounded ANIMO5 application stack advanced from KT11 to KT16.

It does not promote any post-KT11 candidate into central admitted runtime authority, does not admit state or restart schema, does not change B3, and does not open B4 or production.

## Runtime progression since RG06

The candidate stack now reaches a bounded application rather than only a forcing provider.

The path is:

`KT11/KT06 -> bounded science and hydrology seams -> boundary chemistry frame -> composite continuation -> atomic application commit -> immutable application configuration -> accepted-boundary checkpoint/restart`.

The strongest current candidate is KT16. KT16 demonstrates in-memory accepted-boundary checkpoint/restore and exact split-run equivalence for the bounded KT15A application.

That is a substantial runtime qualification result, but it is not central admission. Every post-KT11 composition layer still retains its genuine independent-review gate.

## Central runtime authority

Central admitted runtime authority remains exactly KT06-A1 and KT11-A1. RG07 explicitly prevents the existence of qualified branches from being mistaken for automatic admission.

## Scientific programme state

The B3 aggregate remains incomplete under B3Q06 with TCD-016, TCD-034 and TCD-040 unadmitted.

TCD-016 has progressed beyond the earlier SQ11 parking point to B3B14 closure-readiness analysis. The result is still negative for admission: an explicit model-evolution decision is required and historical behavior remains unknown without B2 evidence.

TCD-034 remains not ready for Class-F admission. Three material gates remain.

TCD-040 has a validated reconstructed replay package, but controlled immutable B0 custody and restore verification remains external and unresolved.

None of these advances changes the B3 aggregate or production gate.

## Candidate review frontier

The runtime candidate stack now contains several Tier-C and Tier-D objects that have passed exact-head CI and same-agent adversarial review but remain not independently reviewed.

Same-agent assurance is process assurance only:

`PROCESS_SELF_REVIEWED_NOT_INDEPENDENT`.

RG07 therefore freezes the current stack and routes genuine independent review as the serial admission gate before any canonical state, checkpoint or composed-application admission.

## Next technical work

Independent review preparation does not prevent ownership-disjoint nonproduction engineering.

KT16 identifies the next narrow technical gap clearly: a checkpoint manifest with integrity, build identity and source/configuration identity binding.

That is suitable for KT17 provided it remains nonproduction and does not silently turn an in-memory candidate record into a canonical checkpoint file format.

External-provider-to-application composition is a second technical route, but should remain separate from KT17.

## Project gates

B3 is incomplete. TB7, B4 and production remain closed. Status A and Status AA are not claimed. The denominator remains unqualified.

Branch counts and green workflows are not a completion metric.

## Hard boundary

RG07 changes governance metadata only. No scientific semantics, production source, queue membership, central runtime admission, canonical state registry or checkpoint schema is modified.
