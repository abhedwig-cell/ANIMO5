# ANIMO-KT14 Qualification Rationale

KT13A proved that explicit chemistry could participate in one bounded TCD-042 transaction, but the chemistry input was not bound to the transaction interval.

BOUNDQ02 now provides that missing time/provenance contract.

KT14 is deliberately thin. It validates the BOUNDQ02 frame against the exact interval and only then delegates science to the remediated KT13A composition. This avoids duplicating hydrology or TCD-042 equations.

The workunit also makes the dry-deposition separation executable: dry deposition remains visible in the boundary frame but is not passed into the wet/advective TCD-042 load path.

Positive qualification would establish:

`A_SELF_VALIDATING_BOUNDQ02_CHEMISTRY_FRAME_BOUND_TO_EXACT_T0_T1_CAN_DRIVE_THE_REMEDIATED_KT13A_ONE_INTERVAL_TCD042_TRANSACTION_WITHOUT_STALE_FRAME_OR_DRY_DEPOSITION_LEAKAGE`.

It would not establish atomic publication of the boundary year cursor or any multi-interval accepted continuation state.
