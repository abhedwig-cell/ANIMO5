# ANIMO-ARCH05 external crop exchange contract

Status: `CANDIDATE_ARCHITECTURE_DESIGN`.

## Ownership modes

ARCH04 defines three crop modes:

- `none`: no crop owner or crop exchange;
- `animo`: persistent crop state is ANIMO-owned;
- `external`: persistent crop state belongs to an external crop model and ANIMO sees only explicit exchange fields.

ARCH05 concerns the third mode. It does not modify the ANIMO-owned crop candidate state defined by ARCH01.

## Evidence basis

PREP06 confirms that realized crop N and P uptake are physical transfers: soil mineral nutrient loss is paired with gain in actual crop nutrient state for a whole soil+crop control volume. PREP06 also separates root death, residue return, harvest export and grazing export from soil-only balance semantics.

This supports an exchange contract in which an external crop owner remains the only persistent owner of crop state while ANIMO returns realized soil-to-crop nutrient transfers explicitly.

## Input frame from crop owner

The candidate crop frame may provide:

- active/inactive crop status;
- root distribution when spatial nutrient-demand allocation needs it;
- N uptake demand/capacity for the interval;
- P uptake demand/capacity for the interval;
- optional accepted/trial crop N and P state observations for combined soil+crop ledger views;
- optional shoot/root dry-matter observations for crop dry-matter ledger views;
- explicit crop-generated residue/exudate return bundles;
- explicit external export bundles when combined crop-system closure is requested.

Only fields required by the active process/diagnostic contract need to be present. Persistent external crop state is not duplicated in ANIMO merely to make optional diagnostics easier.

## Realized uptake result

ANIMO evaluates nutrient availability and process constraints in its trial state and returns realized uptake quantities. The candidate output fields are:

- `CROP-N-UPTAKE-REALIZED`;
- `CROP-P-UPTAKE-REALIZED`.

These are trial results linked to the corresponding ANIMO typed transfer events. They are not direct writes into crop-model memory.

On reject the results are discarded. On coupled accept the crop owner may use the admitted results to promote its own trial state, and the same typed physical transfer is available to the MassLedger view. The transfer must not be recreated independently in both models.

## External crop state observations

Crop N/P and dry-matter begin/end fields are observation coordinates only. They are required only when a combined soil+crop ledger view requests them or another admitted coupled contract explicitly needs them.

The end observation may refer to an unaccepted crop trial. Its snapshot identity must therefore be bound to the same coupled trial metadata as the ANIMO result.

## Residues and exudates

External crop state differences are not a safe proxy for soil additions. A root biomass decrease could represent death, export, remobilization or another crop-internal process.

Therefore any crop-to-soil material generated by an external crop model crosses the boundary as an explicit typed quantity bundle. The bundle identifies at least:

- source crop compartment;
- target ANIMO/soil compartment;
- dry-matter or organic-matter quantity contract;
- N and P composition where applicable;
- interval and event identity.

Any conversion between crop dry matter and ANIMO organic-matter mass must be an explicit admitted conversion contract. ARCH05 does not infer elemental carbon from either representation.

## Harvest and grazing

If whole crop-system accounting is requested, harvest, grazing consumption or other external removals must be exposed as explicit external event observations by the crop owner. They are not inferred as a remainder of ANIMO nutrient uptake or soil balance terms.

This follows PREP06 identities in which harvest return and export and grazing return and export have distinct control-volume roles.

## Water uptake boundary

Hydrological transpiration and soil-water uptake remain part of the hydrology exchange contract. ARCH05 does not duplicate those water transfers in the crop nutrient contract.

A future multi-model orchestrator may bind both hydrology and crop models to the same plant process, but the same physical water transfer must still have one canonical source of truth.

## Compatibility

An external crop frame is valid only when:

- `crop_mode=external`;
- crop exchange schema identity matches;
- crop producer state generation matches the bound trial;
- geometry/root-distribution dimensions match the ANIMO physical layout where required;
- unit contracts match;
- the exact interval/trial binding matches.

Switching between external and ANIMO crop ownership changes physical ownership semantics and is not a normal timestep mutation.

## Not defined here

ARCH05 does not define:

- WOFOST-specific internal state mappings;
- crop phenology or growth equations;
- whether demand is evaluated before or inside an iterative coupled solve;
- coupling iteration or convergence policy;
- numerical tolerances;
- production language ABI.
