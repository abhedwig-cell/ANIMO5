## Scope established from the document

The guide contains:

- a summarized theoretical background for carbon, nitrogen and phosphorus;
- hydrological schematization and transport/transformation concepts;
- internal and external crop uptake routes;
- environmental response functions;
- detailed ANIMO 4.0 input and output descriptions;
- five case studies with reported results and balances;
- an annex describing mass balances;
- an annex with a technical ANIMO 4.0 program description and main-program flow.

The guide explicitly points to Groenendijk and Kroes (1999), Rijtema et al. (1999) and Groenendijk et al. (2005) for more extensive model theory. It is therefore valuable technical evidence but not a complete formal-theory baseline, and it describes ANIMO 4.0 rather than the supplied 4.1.5 revision 53 source.

## Version reconciliation boundary

The guide documents ANIMO 4.0 source structure and parameter dimensions. The supplied source self-identifies as ANIMO 4.1.5 revision 53 and contains later/expanded structures. Differences are registered as documentation/version discrepancies, not automatically as legacy-code defects.
