## Why there is no B3 disposition record yet

The qualified `B3_DISPOSITION_SCHEMA.json` requires every disposition record to select one of two admission routes:

1. `NORMAL_B2_AVAILABLE`, which requires an `AVAILABLE_QUALIFIED_REFERENCE`; or
2. `INDEPENDENT_SCIENTIFIC_ADMISSION_WITH_HISTORICAL_UNCERTAINTY`, which requires B2 to be `UNAVAILABLE_AFTER_DOCUMENTED_ACQUISITION_ATTEMPT` plus the stricter historical-uncertainty evidence package.

PREP10 is currently in neither state. PREP02R still has historical reference recovery open, so B2 is not available, but the acquisition route is also not formally exhausted.

Creating a schema-valid disposition record now would therefore require fabricating either B2 availability or acquisition exhaustion. This intake fails closed instead:

`B3_DISPOSITION_RECORD_DEFERRED_UNTIL_ADMISSION_ROUTE_ELIGIBLE`.

This is a governance result, not a blocker defect in the schema. The schema is designed for disposition records, while this file is a pre-disposition intake/reservation.
